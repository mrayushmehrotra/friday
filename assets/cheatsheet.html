Jarvis Commands

General

  • time — current time
  • briefing / daily briefing / what's new — market data + finance headlines
  • remember ... — saves a note to TODO.txt
  • cheatsheet / help — opens this page

Web & Search

  • open google — opens Google
  • open github — opens your GitHub
  • open terminal — opens Kitty terminal
  • search for ... — web search (via MCP + LLM)
  • what's ... / what is ... / who is ... / tell me about ... — same as search
  • ... on youtube / youtube ... — searches YouTube

News & Finance

  • news / finance / market — latest news on a topic

Clipboard

  • copy ... — copies text to clipboard
  • write ... / right ... — types text at cursor
  • close — sends Ctrl+Q / Ctrl+W
  • summarize clipboard / analyse clipboard / explain clipboard — LLM analysis
  • translate clipboard to ... — translates clipboard content

Tasks / Todos

  • todo / task / what i've to do / what's my — reads your notes/todos

Audio & Volume

  • mute — mute system audio
  • unmute — unmute system audio
  • volume 50 — set volume to 50%

System

  • evade — shuts down the PC
  • open your logs — opens jarvis.log in nvim

Session

  • sleep / goodbye — exits Jarvis
  • daddy's home / daddy is home — welcome message + briefing
